# Морская УКВ · RTL-SDR — версия 2 для Windows (7, 8, 10, 11)

Панель морской радиостанции на RTL-SDR: канал/частота, кнопка 16, ▲▼, SQL/VOL, обзор всего морского диапазона с
быстрым переходом на найденный канал, АИС с выводом NMEA по TCP/UDP (для OpenCPN), запись в MP3.
Окно можно делать вертикальным или горизонтальным — панель перестраивается сама.

## Как получить exe (самый простой способ — GitHub Actions)
1. Загрузите содержимое этой папки в новый репозиторий GitHub (как для Android-версии).
2. Вкладка **Actions → Build Windows (portable exe, Windows 7+) → Run workflow**.
3. Через ~10 минут скачайте артефакт **MarineVHF-win7plus-x64** (zip), распакуйте куда угодно — это portable-папка.
   В ней уже лежат `librtlsdr.dll`, `libusb-1.0.dll`, PortAudio и всё остальное; ничего устанавливать не нужно.

## Сборка вручную на своём компьютере
1. Установите **Python 3.8.10 x64** (последний Python для Windows 7), отметьте «py launcher».
2. Положите в папку `dlls\` файлы `librtlsdr.dll`, `libusb-1.0.dll` (и `libwinpthread-1.dll`, если есть) из x64-сборки rtl-sdr.
3. Запустите `build_exe.bat` → `dist\MarineVHF\MarineVHF.exe`.

## Требования к Windows
- Windows 7 SP1 и новее, 64-бит. Для Windows 7 установите обновление **KB2999226** (Universal C Runtime) —
  оно нужно любому Python 3.8; на Windows 10/11 ставить ничего не нужно.
- Драйвер USB для RTL-SDR (WinUSB через Zadig) — как в версии 1; если ключ уже работал, ничего делать не надо.
- Зависимости (Python, numpy, PortAudio, MP3-кодер, DLL RTL-SDR) входят в сборку. scipy больше не нужен.

## OpenCPN
См. `OpenCPN-подключение.txt`: в OpenCPN добавляется сетевое соединение TCP 127.0.0.1:10110 (вход), после чего
суда с вашего RTL-SDR появляются на карте. `OpenCPN_start.bat` запускает MarineVHF (АИС, свёрнуто) и OpenCPN вместе.
Это внешний источник данных, а не DLL-плагин внутри OpenCPN.

## Управление
Мышь/касание по кнопкам панели. Клавиши: цифры и «.» — ввод, Enter — ввод, Backspace — CLR, ↑/↓ — канал,
Home — канал 16, C — канал/частота, S — скан, A — АИС, R — запись. Клик по столбику «Обзора каналов» — слушать канал.
Колесо мыши над ползунком меняет SQL/VOL. «АВТО-СТОП» — остановка обзора на первом найденном сигнале.

## Что нового по сравнению с версией 1
- Новый интерфейс (вертикальный и горизонтальный вид), рисуется на одном холсте: меньше нагрузки, чёткий на HiDPI.
- Без scipy: собственные фильтры на numpy (совпадают со scipy до 1e-15). Папка программы ~в 3–4 раза меньше,
  запуск быстрее, меньше проблем на Windows 7.
- Ключ можно подключить после запуска программы и переподключать: приёмник сам пробует каждые 2 секунды.
- Отправка NMEA в отдельном потоке: медленный клиент не тормозит приём. Один экземпляр программы.
- Экономия: при свёрнутом окне отрисовка отключается; при закрытом шумодаве звук не отправляется;
  слои перерисовываются только при изменении.
- Настройки сохраняются в `marine_vhf.json` рядом с exe (если папка недоступна для записи — в `%APPDATA%\MarineVHF`).

Проверено автоматически (`python selftest.py`): приём, обзор, декодер АИС, TCP/UDP, MP3, раскладка окна в 7 размерах,
логика приложения с заглушкой Tk (нажатия, ползунки, обзор, АИС, смена ориентации).

реальный RTL-SDR и звук. Если что-то не так — пришлите скриншот или текст ошибки.
